## Project Overview
This project focuses on analyzing NYC Yellow Taxi trip data using Google BigQuery on Google Cloud Platform (GCP). The project includes data cleaning, validation, revenue analysis, and comparison between external and native BigQuery tables.

The goal of this project is to demonstrate cloud-based big data analytics using SQL queries in BigQuery Studio.

---

## Technologies Used
- Google Cloud Platform (GCP)
- Google BigQuery
- SQL
- BigQuery Studio

---

## Dataset
The project uses NYC Yellow Taxi trip data for performing analytical queries and cloud-based data processing.
